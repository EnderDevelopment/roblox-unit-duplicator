# Cameraman Tower Defense Unit Duplicator

This project provides scripts for duplicating units in a Cameraman Tower Defense game. The scripts allow players to duplicate units by looking at them and pressing the 'E' key, provided they have enough gold. The project includes client-side and server-side scripts to handle the duplication process, ensuring that the game logic is properly managed and that players can only duplicate their own units.

## Install

1. Place the `UnitDuplicator.lua` script in the `ServerScriptService` folder.
2. Place the `ClientUnitDuplicator.lua` script in the `StarterPlayerScripts` folder.
3. Place the `ServerUnitDuplicator.lua` script in the `ServerScriptService` folder.

## Use

1. Open Roblox Studio and load your Cameraman Tower Defense game.
2. Place the scripts in the specified locations.
3. Ensure that the units in your game have the necessary attributes (`Cost`, `MaxHealth`, etc.).
4. Start the game and test the unit duplication feature by looking at a unit and pressing the 'E' key.
